## iSCSI VS NFS
- NFS : 네트워크를 통해 폴더 공유 받는 것과 비슷
- iSCSI : 네트워크를 통해 USB 외장하드 꽂는 느낌

| 항목           | **NFS (Network File System)** | **iSCSI (Internet SCSI)**      |
| ------------ | ----------------------------- | ------------------------------ |
| **동작 방식**    | 네트워크를 통한 **파일 단위 공유**         | 네트워크를 통한 **블록 단위 공유**          |
| **마운트 대상**   | 디렉토리 (파일시스템 전체)               | 디스크 (LUN: Logical Unit Number) |
| **OS 인식 방식** | 원격 파일시스템 (예: NFS 마운트)         | 로컬 블록 디바이스 (예: `/dev/sdX`)     |
| **포맷 필요 여부** | ❌ 서버 쪽에서 이미 파일시스템 있음          | ✅ 클라이언트가 파일시스템 포맷 (ext4 등) 필요  |
| **동시 접근**    | ✅ 여러 노드에서 동시에 읽기/쓰기 가능        | ❌ 일반적으로 하나의 노드에서만 마운트 가능       |
| **공유 모델**    | 공유 파일 시스템                     | 전용 디스크처럼 독점 사용                 |
| **성능**       | 파일 I/O 최적화 (메타데이터 오버헤드 있음)    | 디스크 I/O에 가까움 (빠름, DB에 유리)      |
| **복잡도**      | 낮음 (파일 공유만 설정하면 됨)            | 높음 (LUN, IQN, Target 설정 필요)    |
| **대표 사용 예**  | 웹 서버 정적 파일, 공용 데이터            | DB 데이터 디스크, VM 루트 디스크          |

### Kubernetes에서의 활용 차이
| 항목        | **NFS**                        | **iSCSI**            |
| --------- | ------------------------------ | -------------------- |
| 동시 마운트    | ✅ 다중 Pod가 여러 노드에서 사용 가능        | ❌ 일반적으로 단일 노드만 사용 가능 |
| PVC 연결 방식 | `ReadWriteMany` 가능             | `ReadWriteOnce` 사용됨  |
| CSI 필요 여부 | 동적 프로비저닝 시 필요 (ex. nfs-client) | 보통 내장 드라이버로도 가능      |

## 질문
### 질문 : 네트워크 스토리지인데 어떻게 디스크 I/O에 가까울까? 네트워크 속도에 영향을 받지 않나?
### ✅ 먼저, iSCSI는 블록 스토리지다
#### iSCSI는 네트워크를 통해 원격 디스크(LUN)를 제공하지만, 클라이언트에서는 로컬 디스크처럼 /dev/sdX 형태로 인식한다.
#### 이게 핵심이다. 파일 단위가 아니라 블록 단위로 직접 읽고 쓴다.
#### → 그래서 로컬 디스크처럼 작동하고,
#### → 파일시스템 처리 없이 I/O 요청을 바로 블록 레벨로 처리하기 때문에 성능이 더 가까움.
### <br/>

### 그럼에도 네트워크 기반인데 왜 빠른가?
1. **전용 네트워크 환경에서 빠름**
- iSCSI는 일반적으로 전용 스토리지 네트워크 (iSCSI VLAN) 을 따로 구성함.
- 속도: 일반적으로 10Gbps, 25Gbps, 요즘은 100Gbps NIC도 많음.
- 로컬 디스크에 가까운 처리 속도를 낼 수 있음.
2. **TCP 기반 최적화**
- iSCSI는 TCP/IP 위에서 작동함.
- 대용량 전송에 적합하게 조정된 흐름 제어, 재전송, 버퍼링 등을 갖춰서 지속적인 Throughput이 유지됨.
3. **디스크 I/O 특성**
- 데이터베이스, VM, 로그 저장 등에서 iSCSI는 랜덤 I/O 보다 순차적 블록 I/O에 강함.
- 이는 로컬 SSD에도 가까운 특성임.
### <br/>

### 그렇다고 완전히 로컬 디스크처럼 빠른 건 아니다.
| 항목                 | 설명                                            |
| ------------------ | --------------------------------------------- |
| **네트워크 병목**        | 있음. 특히 공유 네트워크, 1Gbps 이하 네트워크에서는 성능 급락        |
| **지연 시간(latency)** | 로컬 SSD보다는 높음. 네트워크 왕복 시간은 어쩔 수 없음             |
| **패킷 손실**          | 스토리지 트래픽은 신뢰성 높게 설계되어 있지만, 네트워크 품질이 낮으면 영향 받음 |
